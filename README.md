# Asif Barakat Chowdhury — Portfolio

A fast, animated single-page portfolio built with **React 19 + Vite + Tailwind CSS v4 + Framer Motion**.

🔗 **Live site:** https://portfolio-jet-omega-86.vercel.app/

---

## ✨ Highlights

- SQA & SDET portfolio with live k6-style telemetry demo console
- Featured testing & software engineering projects (E2E suites, offline P2P mesh, desktop tools)
- Systems research highlight: Adaptive Split Computing & Feature Extraction with reproducible metrics
- Responsive layout, keyboard focus navigation, Open Graph preview card, and `prefers-reduced-motion` support

## 🛠 Tech Stack

| Tool | Purpose |
|---|---|
| Vite 7 | Build tool & dev server |
| React 19 | UI library |
| Tailwind CSS v4 | Styling (utility classes) |
| Framer Motion | Animations |
| react-icons | Icons |

## 🚀 Getting Started

```bash
npm install      # install dependencies
npm run dev      # start dev server → http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## ✏️ Editing your content

All text, skills, projects, and research live in **one file**:

```
src/data/portfolio.js
```

Edit the values there and the whole site updates — no component code needs to change.

## ☁️ Deploy

This site deploys to [Vercel](https://vercel.com) or [Netlify](https://netlify.com)
with zero config — the framework is auto-detected (build: `npm run build`, output: `dist`).
